### 2026-09-14 — `\map` + `\geral` — Reset da rosa e criação do `\ajuda` + instalador global

- **Papéis usados:** `\map`, `\geral`, `\devops` (instalação), `\tech` (desenho
  do gerador).
- **Objetivo:** (1) valer em todos os projetos; (2) criar o comando `\ajuda`
  com a lista detalhada; (3) transformar a `rosa` no projeto **portátil** dos
  comandos (para outras IAs, não só Cline), sem misturar com a instalação global;
  (4) cheat-sheet; (5) apagar o projeto antigo.
- **Decisões + motivo:**
  1. Usar `Documents\Cline\Rules\` como instalação global — é o caminho oficial
     do Cline no Windows (confirmado na documentação).
  2. A `rosa` virou **fonte da verdade** (`catalogo/`) + **gerador**
     (`gerar.ps1` → `dist/`). Assim o mesmo texto serve para 7 IAs diferentes.
  3. Texto do catálogo foi reescrito para ser **agnóstico de ferramenta**
     (não diz mais "Cline" no lugar de "a IA").
  4. Cheat-sheet **fora** da pasta `Rules` (evitar ~3 KB em todo prompt).
  5. Backup em `.zip` **antes** de apagar o projeto antigo (não havia git).
- **Arquivos criados/alterados:** todos os listados em "Estrutura atual" +
  `dist/` (19 arquivos gerados).
- **Comando de teste:**
  ```powershell

  Get-ChildItem C:\Users\joaqu\rosa\dist -Recurse -File
  ```
